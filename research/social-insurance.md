# 中国五险一金事实表（2025 社保年度 / 2026 现行）

> **用途**：为「中国劳动收入组成桑基图」提供单位用工成本 → 五险一金 → 个人/统筹/财政 的资金流事实依据。
> **数据截止**：2026-11-20。**主要目标年度**：2025 社保年度（2025-07-01 ~ 2026-06-30）；同时给出**现行 2026 社保年度**（多数地区 2026-07-01 起）用于对照。
> **来源分级**（每行都标）：
> - **【官方】** 政府/局委原文，可点开核对；
> - **【试算】** 第三方计算器（社保薪税通 shebao.org）按官方基数 + 配置费率生成，费率未必逐项有官方原文；
> - **【常见】** 实务通行做法，无单一官方文件；
> - **【待核实】** 未拿到原文，仅作线索。
>
> 术语：**社保年度**≠自然年。上海/北京/广东/河南按 **7-01 至次年 6-30**；浙江/四川/江苏/山东/湖南/重庆/陕西/安徽 按 **自然年 1-01 至 12-31**；天津 9-01、湖北 10-01 起算。

**关于上海医保的三个具体疑问（逐条回答）：**
1. **单位 9% 还是 9.8%？→ 9%**。官方拆分为「基本医疗保险费（含生育保险）8.5% + 地方附加医疗保险费 0.5%」。9.8% 是**北京**口径，不是上海。
2. **个人 2% 之外是否有 +3 元大病？→ 上海没有**。上海个人固定 2%，无按人头附加；「个人 2% + 3 元/月大额医疗互助」是**北京**做法【待核实原文，见 §9】。
3. **失业 0.5%/0.5%？→ 是**（单位 0.5% + 个人 0.5%，合计 1%），但属阶段性降费，需按年续期。

> 上海医保文件**有效期至 2027-02-28**，属「阶段性降费」按年续发——桑基图若跨年对比，必须按年重新取证。

**结论：2025-07-01 确实调整了**，下限 +76 元（+1.03%）、上限 +381 元（+1.03%），社平从 12307 涨到 12434。年度涨幅约 1.0%~1.15%，属「低增长」年份（2021 年前常见 8%~10% 涨幅）。

## 4. 灵活就业 / 城乡居民 / 4050

| 上海合计 | 养老 20% + 医保 10% = **30%**，基数 7546–37731（2026 年度） | 【官方费率 + 官方基数】组合 | 同上 + https://rsj.sh.gov.cn/tgsgg_17341/20260818/t0035_1443203.html |

- **缴费负担对比（关键事实）**：同样按 10000 基数，职工个人只出 10.5%（1050 元），灵活就业者要出 **30%（3000 元）**——因为原本由单位承担的 16% 养老 + 9% 医保全部落到个人头上。这是「灵活就业参保率低」的核心经济原因。
- 上海灵活就业医保曾为 11%，2026-03 起按新规为 **10%**【官方文件口径】；「11%」是旧口径，做历史对比时需分段。

| 拆分工资 | 一部分走工资、一部分走报销/劳务/个体户 | 【常见】 | 税务与社保数据比对后风险上升 |

## 8. 单位用工总成本算例：月薪 10000，上海

**假设**：2026 社保年度（下限 7546、上限 37731），基数按实际工资 10000；公积金单位/个人各 **7%**；工伤按上海平均实缴 **0.26%**【试算值】；不含补充公积金；个税按首月累计预扣。

### 8.1 个人扣款（工资单「五险一金」栏）

| 项目 | 费率 | 金额（元） |
|---|---|---|
| 养老 | 8% | 800.00 |
| 医疗 | 2% | 200.00 |
| 失业 | 0.5% | 50.00 |
| 工伤/生育 | 0% | 0.00 |
| **五险小计** | **10.5%** | **1050.00** |
| 公积金 | 7% | 700.00 |
| **个人合计** | **17.5%** | **1750.00** |

**个税**：应纳税所得额 = 10000 − 1050 − 700 − 5000 = **3250 元** → 首月预扣 3250×3% = **97.50 元**。
**到手现金** = 10000 − 1050 − 700 − 97.5 = **8152.50 元**。

### 8.2 单位成本

| 项目 | 费率 | 金额（元） |
|---|---|---|
| 养老 | 16% | 1600.00 |
| 医疗（含生育） | 9% | 900.00 |
| 失业 | 0.5% | 50.00 |
| 工伤 | 0.26%（试算均值） | 26.00 |
| **五险小计** | **25.76%** | **2576.00** |
| 公积金 | 7% | 700.00 |
| **单位合计** | **32.76%** | **3276.00** |

**单位总成本 = 10000 + 3276 = 13276 元/月**，即**工资的 132.76%**。

### 8.3 资金流向拆解（供桑基图直接用）

| 流向 | 金额（元） | 占工资比 | 说明 |
|---|---|---|---|
| 个人到手现金 | 8152.50 | 81.53% | 已扣五险一金与个税 |
| 个人公积金账户 | 700.00 | 7.00% | 归个人所有，可提取/贷款 |
| 个人养老金账户 | 800.00 | 8.00% | 8% 全部入个人账户 |
| 个人医保账户 | 200.00 | 2.00% | 个人 2% 全额入账户 |
| 个人失业（进统筹） | 50.00 | 0.50% | 个人缴 0.5%，进失业保险基金 |
| 个人所得税 | 97.50 | 0.98% | 首月，后续月份累计预扣会上升 |
| 统筹基金（养老 16% + 失业 + 工伤） | 1676.00 | 16.76% | 单位缴，进社会统筹 |
| 统筹基金（医疗 9%） | 900.00 | 9.00% | 单位缴，进医保统筹 |
| 单位公积金 | 700.00 | 7.00% | 归个人所有 |
| **合计** | **13276.00** | **132.76%** | 单位总成本 |

**若含补充公积金 5%（上海国企/外企常见）**：单位与个人各再加 500 元 → 单位成本 **13776 元（137.76%）**，个人公积金账户当月进 **1200 元**，到手降至 **7652.50 元**。

**若单位违规按最低基数 7546 申报**：单位五险降为 7546×25.76% = 1943.9 元、个人五险降为 792.3 元，单位每月省约 632 元、个人当月多拿约 258 元，但养老/医保/生育待遇同步缩水——这正是「基数脱节」的经济动机。
