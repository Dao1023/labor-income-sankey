# 中国劳动/用工形态全景事实表

> 项目：中国劳动收入组成桑基图（labor-income-sankey）
> 用途：为桑基图提供可计算的收入结构参数与预设案例
> 口径年份：2025 年末（政策与费率），2026 年可能调整
> 性质：研究底稿，不是法律意见；所有比例为**估算区间**，不是精算值

---

## 0. 阅读说明

### 0.1 三个标记

| 标记 | 含义 |
|---|---|
| **【制度】** | 有法律、行政法规、部门规章或国家统一政策依据，全国适用（地方细则可能不同） |
| **【常见做法，非普遍】** | 市场中反复出现、但无制度依据或普遍违法的做法；不能当作"所有企业都这样" |
| **【估算】** | 基于公开招聘信息、行业访谈、统计口径推算的区间，误差可达 ±30% |

### 0.2 收入口径

- 卡片中的"月收入"= **税前应发**，已把年终奖/十三薪摊到 12 个月，**不含**单位缴纳的社保、公积金、年金。
- "到手"= 应发 − 个人社保 − 个人公积金 − 个税。**公积金和年金个人账户的钱归个人**，所以另设"全口径到手"概念。
- 一线 = 北上广深；二线 = 省会/强地级市；三线 = 普通地级市/县域。同一形态在三地的差异，主要来自**社平工资、财政能力、最低工资**，不是技能差异。

### 0.3 成本倍数定义

```
单位总成本 = 应发工资 + 单位社保 + 单位公积金 + 单位年金 + 管理费/服务费 + 其他用工费用
现金到手   = 应发工资 − 个人社保 − 个人公积金 − 个税
成本倍数   = 单位总成本 ÷ 现金到手
```

这个倍数对公积金比例极其敏感：公积金 12% 时倍数会被抬高，但钱进了员工账户，所以同时给"全口径到手"（现金 + 个人公积金 + 个人年金）更有解释力。

### 0.4 一个必须先讲清的结构性事实

中国劳动收入不是"工资 − 税"两条线，而是**四层楔子**：

1. **社保缴费**（单位 26%–38%，个人 10.5% 左右）——基数常不等于工资；
2. **公积金**（5%–12%，双边）——是强制储蓄，不是税；
3. **个税**（综合所得 3%–45%，劳务报酬预扣 20%–40%，经营所得 5%–35%）——**税目不同，同一笔钱税负差一倍**；
4. **用工中介**（派遣管理费 8%–15%、外包服务费 15%–30%、平台抽成 10%–30%）——这部分不进财政，也不进劳动者口袋。

桑基图如果只画"工资→税→到手"，会漏掉第 1、2、4 层，而这三层恰恰是不同用工形态差异最大的地方。

## 1. 分类树：按"谁承担用工风险"划分

制度上真正决定收入结构的，不是行业，而是下面四个变量：

- **法律关系**：劳动合同 / 劳务 / 承揽 / 无合同
- **社保缴费主体**：单位足额 / 单位低基数 / 自己缴 / 没人缴
- **税目**：工资薪金 / 劳务报酬 / 经营所得 / 不申报
- **收入波动来源**：绩效、计件、佣金、平台派单、项目制

按此分为 8 组、40 种主形态，另附 18 种长尾形态：

```
A 体制内         A1 公务员  A2 教师  A3 医生  A4 军队文职  A5 选调生  A6 社工/公益岗
B 国企           B1 正式工  B2 劳务派遣
C 民企正规       C1 合同工  C2 销售提成  C3 计件工  C4 小时工/非全日制
D 派遣与外包     D1 派遣  D2 人力外包驻场  D3 项目外包  D4 业务外包/个体户  D5 灵活用工平台
E 大厂/金融/外企 E1 互联网  E2 金融  E3 外企  E4 律所/会计所
F 平台零工       F0 灵活就业  F1 众包骑手  F2 专送骑手  F3 网约车  F4 代驾  F5 主播/MCN  F6 家政  F7 保安保洁
G 非标用工       G1 日结零工  G2 建筑包工头  G3 装修工  G4 货运司机
H 特殊身份       H1 实习生  H2 管培生  H3 规培生  H4 博士后  H5 退休返聘  H6 兼职副业  H7 跨境远程

```

**为什么这 40 种不能合并**：桑基图的每一条流，最终要落到"谁付钱、付了什么名目、扣了什么"。A1 和 C1 都是"月薪 + 年终"，但 A1 有职业年金 12%（单位 8 + 个人 4）而 C1 多数没有；D1 和 C1 工资可能一模一样，但 D1 多一道 8%–15% 管理费且社保基数被压低。这些差异在图上就是不同的流。

| **社保公积金** | 军队保障体系；公积金 12%；职业年金按军队规定执行（公开信息少，多数未见单独建立） |
| **个税** | 工资薪金；部分军队津贴按政策免税，实际以单位代扣为准 |
| **成本/到手** | 1.5–1.7 |
| **坑** | 身份介于军人与公务员之间，社会认知低；调动难、落户随单位；体检政审严格 |

#### A5 选调生

| 维度 | 事实 |
|---|---|
| **法律关系** | 同 A1，公务员身份；定向选调另有服务期协议 |
| **月收入** | 同 A1；定向选调常见一次性安家费/人才补贴 5–30 万【常见做法，非普遍】 |
| **收入构成** | 同 A1；安家费为一次性、不计入月薪 |
| **社保公积金** | 同 A1 |
| **个税** | 工资薪金；安家费按当地政策，多数并入综合所得 |
| **成本/到手** | 1.8–2.0 |
| **坑** | 服务期一般 5 年，违约要退补贴并赔违约金；基层锻炼 2 年；"承诺的待遇"常以当地财政为准 |

#### A6 社区工作者/网格员/公益性岗位

| 维度 | 事实 |
|---|---|
| **法律关系** | 【制度】劳动合同（政府购买服务/街道直签）；公益岗为过渡性安置 |
| **月收入** | 一线 5–8k｜二线 4–6k｜三线 3–4.5k |
| **收入构成** | 基本 70–80%｜绩效 10–20%｜补贴 5–10% |
| **社保公积金** | 单位缴职工五险，基数多为实际工资或最低；公积金 5–12%（很多仅 5%）；无年金 |
| **个税** | 工资薪金，多在起征点附近 |
| **成本/到手** | 1.3–1.45 |
| **坑** | "三岗十八级"薪酬体系，涨薪靠年限；公益岗一般 3 年到期退出；财政紧张时绩效拖欠 |

### 3.2 国企

#### B1 央企/地方国企正式工（合同制）

| 维度 | 事实 |
|---|---|
| **法律关系** | 【制度】劳动合同；工资总额由国资监管机构核定 |
| **月收入** | 一线 10–25k｜二线 7–15k｜三线 5–10k；金融/能源类国企更高 |
| **收入构成** | 基本 50–60%｜绩效 20–30%｜年终 10–20%｜补贴 5–10% |
| **社保公积金** | 单位足额：养老 16%、医疗 9–10%、失业 0.5%、工伤 0.2–1%；公积金 12%（部分另有补充 1–5%）；企业年金单位 4–8%+个人 1–4%【制度，覆盖率国企高、民企极低】；补充医疗常见 |
| **个税** | 工资薪金；年终单独计税；企业年金个人缴费 4% 以内税前扣除 |
| **成本/到手** | 1.75–1.95 |
| **坑** | 工资总额封顶，"效益不好就砍年终"；降本增效先砍派遣和外包；子弟/关系户在部分老国企仍是隐性规则 |

#### B2 国企劳务派遣

| 维度 | 事实 |
|---|---|
| **法律关系** | 【制度】与派遣公司签 2 年以上固定期限劳动合同，派至国企 |
| **月收入** | 一线 5–8k｜二线 4–6k｜三线 3–4.5k |
| **收入构成** | 基本 70–85%｜绩效 10–20%｜年终 0–0.5 个月 |
| **社保公积金** | 派遣公司缴，基数常按下限【常见做法，非普遍】；公积金 5% 或仅单边 |
| **个税** | 工资薪金 |
| **成本/到手** | 1.35–1.5（甲方成本含 8–15% 管理费） |
| **坑** | 同工不同酬；转正通道极窄；《劳务派遣暂行规定》10% 比例红线常被"假外包"绕过；低基数导致退休金差距在 20 年后才显现 |

### 3.3 民企正规用工

#### C1 民企正式合同工

| 维度 | 事实 |
|---|---|
| **法律关系** | 【制度】劳动合同（固定期限/无固定期限） |
| **月收入** | 一线 6–15k｜二线 5–10k｜三线 3.5–7k |
| **收入构成** | 基本 60–75%｜绩效 15–25%｜年终 0–10%（常见 1 个月）｜补贴 0–5% |
| **社保公积金** | 分两个子型：**足额型**（拟上市、外企供应商、规范大民企）按实际工资缴；**低基数型**按最低基数或打折基数缴【常见做法，非普遍】。公积金 5–8%，很多按最低工资基数 |
| **个税** | 工资薪金，累计预扣 |
| **成本/到手** | 足额 1.4–1.55；最低基数 1.22–1.35 |
| **坑** | 低基数直接压低养老/医保/生育/失业待遇；2025-09-01 起最高法司法解释明确"自愿放弃社保"约定无效，员工可据此解除并索经济补偿；"大小周"普遍 |

#### C2 销售/提成制

| 维度 | 事实 |
|---|---|
| **法律关系** | 【制度】劳动合同；但底薪常压到最低工资 |
| **月收入** | 一线底薪 4–8k+提成，综合 8–30k｜二线 3–6k+提成，6–20k｜三线 2.5–5k+提成，4–12k |
| **收入构成** | 底薪 25–45%｜提成 45–65%｜补贴/奖金 5–10% |
| **社保公积金** | 常按底薪或最低基数缴【常见做法，非普遍】；公积金 5% |
| **个税** | 工资薪金，提成并入当月，可能导致单月跳档 |
| **成本/到手** | 1.2–1.4 |
| **坑** | 提成递延（次月/季度/年底）；离职扣回；坏账扣提成；底薪低于当地最低工资属违法但常见 |

#### C3 制造业计件工

| 维度 | 事实 |
|---|---|
| **法律关系** | 【制度】劳动合同；计件工资制需约定单价与定额 |
| **月收入** | 一线 6–9k（含加班）｜二线 5–7.5k｜三线 4–6k；旺季可达 8–12k |
| **收入构成** | 底薪（多按最低工资）25–40%｜计件 40–55%｜加班费 15–30%｜补贴 5–10% |
| **社保公积金** | 按最低基数缴【常见做法，非普遍】；公积金 5% 或没有 |
| **个税** | 工资薪金，多数在起征点附近或低档 |
| **成本/到手** | 1.25–1.4 |
| **坑** | 计件单价可被单方面下调；加班费基数按最低工资算；淡旺季收入落差 2–3 倍；工伤与职业病高发 |

#### C4 制造业小时工/非全日制

| 维度 | 事实 |
|---|---|
| **法律关系** | 【制度】非全日制劳动合同：日均 ≤4 小时、周均 ≤24 小时；工资结算周期 ≤15 日 |
| **月收入** | 一线 22–35 元/时，月 3–6k｜二线 18–28 元/时｜三线 15–22 元/时 |
| **收入构成** | 小时工资 90%+｜无奖金、无年终 |
| **社保公积金** | 【制度】工伤险必缴；养老、医疗可不缴（由个人以灵活就业身份缴）；公积金无 |
| **个税** | 工资薪金 |
| **成本/到手** | 1.05–1.12 |
| **坑** | 4 小时/24 小时上限被普遍突破，实际按全日制用但不给全日制待遇；无经济补偿；15 日结算常变成月结 |

### 3.4 派遣与外包

#### D1 劳务派遣

| 维度 | 事实 |
|---|---|
| **法律关系** | 【制度】三方关系：劳动者—派遣公司（劳动合同）—用工单位（劳务派遣协议）；仅限临时性、辅助性、替代性岗位；用工比例 ≤10% |
| **月收入** | 一线 5–9k｜二线 4–7k｜三线 3–5k |
| **收入构成** | 基本 70–85%｜绩效 10–20%｜补贴 0–5%｜基本无年终 |
| **社保公积金** | 【制度】由派遣单位缴纳；实际多按下限【常见做法，非普遍】；公积金 5% |
| **个税** | 工资薪金；派遣公司按差额征税（5%） |
| **成本/到手** | 1.35–1.55（用工单位支付 = 工资 + 社保 + 管理费 8–15%） |
| **坑** | 【制度】同工同酬是原则，但"同工"认定难；10% 红线催生"假外包"；2025 年社保新规后，低基数派遣的合规风险上升 |

#### D2 人力外包（驻场）

| 维度 | 事实 |
|---|---|
| **法律关系** | 劳动者与外包公司签劳动合同，被派到甲方场地工作；甲方与外包公司是服务合同 |
| **月收入** | 一线 7–12k｜二线 5–8k｜三线 4–6k；甲方按人天报价 15–25k |
| **收入构成** | 基本 80–90%｜绩效 5–10%｜补贴 0–5% |
| **社保公积金** | 外包公司缴，多按最低基数【常见做法，非普遍】；公积金 5% |
| **个税** | 工资薪金；外包公司向甲方开 6% 增值税专票（人力资源服务） |
| **成本/到手** | 甲方口径 1.7–2.1（含外包公司 15–30% 服务费与利润） |
| **坑** | 同工不同酬、无归属感；项目结束即退场；"假外包真派遣"被认定后，甲方承担连带责任 |

#### D3 项目外包（B2B）

| 维度 | 事实 |
|---|---|
| **法律关系** | 承揽/服务合同，公司与公司之间；劳动者与承包方签劳动合同 |
| **月收入** | 与 C1 接近：一线 6–15k｜二线 5–10k｜三线 3.5–7k |
| **收入构成** | 同 C1 |
| **社保公积金** | 承包方缴，基数常低【常见做法，非普遍】 |
| **个税** | 工资薪金；发票税目 6%（信息技术服务）、9%（建筑）、13%（货物） |
| **成本/到手** | 甲方口径 1.7–2.0 |
| **坑** | 承包方跑路/欠薪；层层分包；甲方直接管理外包员工会被认定事实劳动关系 |

#### D4 业务外包/个体户承包

| 维度 | 事实 |
|---|---|
| **法律关系** | 承揽；个人注册个体工商户，与平台/甲方签服务协议 |
| **月收入** | 一线 8–20k｜二线 6–15k｜三线 4–10k |
| **收入构成** | 经营收入 100%，无工资名目 |
| **社保公积金** | 无单位缴；个人以灵活就业身份自缴（养老 20%+医疗 8–10%），可不缴 |
| **个税** | 经营所得 5%–35%；核定征收综合税负常见 0.5%–3%【常见做法，非普遍】；小规模纳税人月 10 万以下免增值税 |
| **成本/到手** | 1.05–1.15（含代账/平台费） |
| **坑** | 被认定劳动关系后需补社保（骑手/外卖判例）；虚开发票风险；平台爆雷 |

#### D5 灵活用工平台（委托代征）

| 维度 | 事实 |
|---|---|
| **法律关系** | 个人—平台：承揽/合作；平台受税务机关委托代征 |
| **月收入** | 一线 5–15k｜二线 4–10k｜三线 3–8k |
| **收入构成** | 任务/服务收入 100% |
| **社保公积金** | 无；个人自缴或干脆不缴 |
| **个税** | 经营所得，按核定征收率（常见 0.5%–1.5%）或应税所得率 10% 计算；平台服务费 3%–8% |
| **成本/到手** | 1.05–1.12 |
| **坑** | 2025 年 6 月《互联网平台企业涉税信息报送规定》后，平台按季报送收入信息，"不申报"空间收窄；虚开、洗钱风险 |

### 3.5 大厂/金融/外企

#### E1 互联网大厂

| 维度 | 事实 |
|---|---|
| **法律关系** | 【制度】劳动合同；普遍实行不定时/综合工时（需审批） |
| **月收入** | 一线 25–60k（P6–P8）｜二线（杭州/成都/武汉）18–40k｜三线 12–25k |
| **收入构成** | base 70–80%｜绩效年终 10–20%（3–6 个月）｜RSU/期权 5–10%｜餐补/房补/交通 3–8% |
| **社保公积金** | 足额，基数封顶（当地社平 3 倍）；公积金 12%（杭州/上海部分有补充 5%）；补充商保、免费三餐、班车 |
| **个税** | 工资薪金；RSU 归属日按市价计入工资薪金（境内上市公司可单独计税）；年终单独计税；期权行权同 |
| **成本/到手** | 1.75–1.95（高公积金推高倍数，但钱归个人） |
| **坑** | 35 岁隐性门槛；361 绩效强制分布；股票高位归属后下跌仍按归属日计税；"弹性工作制"规避加班费；竞业协议 |

#### E2 金融机构（券商/基金/银行）

| 维度 | 事实 |
|---|---|
| **法律关系** | 劳动合同；高管/保代另有监管备案 |
| **月收入** | 一线投行/研究 20–80k｜二线 12–30k｜三线 8–20k；银行柜员 6–12k |
| **收入构成** | base 40–60%｜绩效/年终 30–50%（好年景 12–24 个月）｜补贴 5–10% |
| **社保公积金** | 足额；公积金 12%+补充 5%（上海）；部分有企业年金；补充商保 |
| **个税** | 工资薪金；奖金递延部分按实际发放年度计税；递延比例常见 40% 分 3 年【制度，监管要求】 |
| **成本/到手** | 1.7–1.95 |
| **坑** | 限薪（券商高管 300 万）；绩效递延+追索扣回（"反向讨薪"）；行情差时奖金归零但 base 低 |

#### E3 外企

| 维度 | 事实 |
|---|---|
| **法律关系** | 劳动合同（多为无固定期限） |
| **月收入** | 一线 15–40k｜二线 10–25k｜三线 6–15k |
| **收入构成** | base 80–90%｜bonus 10–20%（1–3 个月）｜补贴 3–8%｜股票（部分） |
| **社保公积金** | 足额；公积金 12%+补充（上海 5%）；补充商保含家属；部分有企业年金 |
| **个税** | 工资薪金；外籍员工有专项附加扣除与税收协定 |
| **成本/到手** | 1.7–1.9 |
| **坑** | 裁员 N+1/N+3；玻璃天花板；全球薪资带宽决定涨薪上限；汇兑与跨境股权税务 |

#### E4 律所/会计师事务所

| 维度 | 事实 |
|---|---|
| **法律关系** | 授薪律师：劳动合同；提成律师：挂所合作，非劳动关系；合伙人：合伙协议 |
| **月收入** | 授薪 8–20k（红圈所 EL 3–4 万）｜提成律师无底薪，创收 50–70% 提成｜合伙人分红 |
| **收入构成** | 授薪：base 80%+奖金 20%；提成：创收 100%，提成 50–70%，自担成本 |
| **社保公积金** | 授薪由所里缴；提成律师社保全部自担（挂所）或所里代缴后从提成扣；公积金多数无 |
| **个税** | 授薪工资薪金；提成律师按经营所得（部分地方核定）；合伙人经营所得 |
| **成本/到手** | 授薪 1.6–1.8；提成 1.1–1.3（自担社保/座位费/案源费） |
| **坑** | 提成律师"看起来自由，实际自负盈亏"；案源费 20–30%；开票税点；红圈所工时 3000+ |

### 3.6 平台、零工与灵活就业

#### F0 灵活就业/自由职业（非平台）

| 维度 | 事实 |
|---|---|
| **法律关系** | 无单位；与客户是劳务/承揽关系；可自愿注册个体工商户 |
| **月收入** | 一线 8–25k｜二线 5–15k｜三线 4–10k（项目制，月度方差可达 3 倍） |
| **收入构成** | 项目/服务收入 90%+｜平台或中介抽成 0–20% |
| **社保公积金** | 自缴：养老 20% + 医疗 8–10%，基数可在社平 60%–300% 间选；公积金自愿缴（部分城市试点）；多数人只缴养老或干脆断缴 |
| **个税** | 劳务报酬（20%–40% 预扣，年度汇算并入综合所得）或经营所得（5%–35%，可核定）；小规模个体户月 10 万以下免增值税 |
| **成本/到手** | 1.0（不缴社保）；自缴社保后约 1.3–1.5（按净现金） |
| **坑** | 收入不稳定、社保断缴、劳务报酬预扣率高导致现金流紧、甲方拖欠、议价能力随年龄下降；"灵活"常等于"无保障" |

#### F1 外卖骑手（众包）

| 维度 | 事实 |
|---|---|
| **法律关系** | 【制度】多数被定位为"依托平台自主经营"，无劳动关系；2021 年 56 号文分三类 |
| **月收入** | 一线 7–12k｜二线 5–9k｜三线 4–7k（按单 4–8 元，日均 30–60 单） |
| **收入构成** | 按单计酬 90%+｜恶劣天气/冲单奖励 5–10% |
| **社保公积金** | 无；职业伤害保障试点按单缴费（平台承担，每单几分到 0.1 元）【制度，2022 起 7 省市，2025 扩围】；养老医疗自缴 |
| **个税** | 经营所得（平台委托代征，核定 0.5%–1.5%）或劳务报酬 |
| **成本/到手** | 1.05–1.12（含平台服务费/保险） |
| **坑** | 算法派单与超时罚款；事故责任认定难；众包与专送待遇差；"个体工商户"注册后失去劳动者身份 |

#### F2 外卖骑手（专送/加盟商）

| 维度 | 事实 |
|---|---|
| **法律关系** | 与站点/加盟商签劳动合同或承揽协议，实践中多为"合作协议" |
| **月收入** | 一线 8–13k｜二线 6–10k｜三线 5–8k |
| **收入构成** | 底薪 20–30%｜单量提成 60–70%｜补贴 5–10% |
| **社保公积金** | 加盟商多为小公司/个体户，多数不缴或按最低【常见做法，非普遍】；无公积金 |
| **个税** | 若认定劳动关系为工资薪金；否则经营所得 |
| **成本/到手** | 1.15–1.3 |
| **坑** | 站点罚款名目多；离职扣款；加盟商跑路；劳动关系认定靠仲裁/诉讼 |

#### F3 网约车司机

| 维度 | 事实 |
|---|---|
| **法律关系** | 承揽/合作，无劳动关系；需"双证"（人证、车证） |
| **月收入** | 一线流水 10–18k｜二线 8–13k｜三线 6–10k；到手约为流水 55–65% |
| **收入构成** | 流水 100%；平台抽成 18–30%；油/电/租车/保险 20–30% |
| **社保公积金** | 无；可自缴灵活就业社保（多数不缴） |
| **个税** | 经营所得/劳务报酬；多数未申报【常见做法，非普遍】 |
| **成本/到手** | 1.0（平台抽成已在流水内扣除） |
| **坑** | 双证与运管罚款；租车押金；平台抽成不透明；车辆折旧算进去后时薪可能低于最低工资 |

| 维度 | 事实 |
|---|---|

| **月收入** | 一线 8–15k｜二线 6–10k｜三线 4–7k |
| **收入构成** | 按单 90%+｜平台信息费 10–20% |
| **社保公积金** | 无 |
| **个税** | 经营所得/劳务报酬，多未申报 |
| **成本/到手** | 1.0–1.05 |
| **坑** | 夜间安全与人身风险；封号即断收入；事故保险理赔争议 |

#### F5 主播/MCN

| 维度 | 事实 |
|---|---|
| **法律关系** | 三种：签约员工（劳动合同）、合作分成（劳务）、工作室/个体户（经营） |
| **月收入** | 底部 3–8k｜腰部 10–50k｜头部 100k+（分布极陡，中位数远低于均值） |
| **收入构成** | 底薪 20–40%｜打赏分成 30–50%｜带货佣金 10–30%｜坑位费（另计）；MCN 分成 30–70% |
| **社保公积金** | 签约员工由 MCN 缴；合作/个体户自缴；多数底部主播无社保 |
| **个税** | 工资薪金/劳务报酬/经营所得（工作室核定）；2021 年后直播行业税务稽查常态化 |
| **成本/到手** | 1.1–2.0（MCN 分成是最大"楔子"） |
| **坑** | 天价违约金；打赏分成不透明；封号断供；税务补缴风险 |

#### F6 家政/月嫂/住家保姆

| 维度 | 事实 |
|---|---|

| **月收入** | 住家保姆 一线 6–12k｜二线 4–8k｜三线 3–5k；月嫂 一线 12–25k｜二线 8–15k｜三线 6–10k |
| **收入构成** | 工资 95%+｜无奖金、无年终 |
| **社保公积金** | 中介制无；员工制家政有职工社保（行业占比低）；多数只买商业意外险 |
| **个税** | 基本不申报【常见做法，非普遍】 |
| **成本/到手** | 1.0–1.05 |
| **坑** | 住家工时无边界；月嫂 26 天工作制；雇主家庭安全与隐私风险；中介费抽成 |

#### F7 保安/保洁

| 维度 | 事实 |
|---|---|

| **个税** | 工资薪金，多在起征点以下 |

## 4. 制度参数速查（2025 年末口径）

### 4.1 社保缴费率（代表性区间，各地有差异）

| 险种 | 单位 | 个人 | 说明 |
|---|---|---|---|
| 养老保险 | 16% | 8% | 浙江/广东部分城市有 14%–15% 过渡；灵活就业 20% 全自担 |
| 医疗保险 | 6%–10% | 2%（+3 元大病） | 多数地区生育已并入医疗 |
| 失业保险 | 0.5%–0.8% | 0.2%–0.5% | 部分地区阶段性降费 |
| 工伤保险 | 0.2%–1.9% | 0 | 行业差别费率，个人不缴 |
| 生育保险 | 0.5%–1% | 0 | 多数已并入医疗 |
| 住房公积金 | 5%–12% | 5%–12% | 双边同比例；上海另有补充公积金 1%–5% |
| 职业年金 | 8% | 4% | 仅机关事业单位编制内 |
| 企业年金 | ≤8% | ≤4% | 单位+个人合计 ≤12%，税前扣除 |

**缴费基数**：上年度全口径城镇单位就业人员平均工资的 60%–300%。2025 年参考：上海下限约 7,400 元、上限约 36,900 元；北京下限约 6,800 元、上限约 35,300 元；三四线下限 3,500–4,500 元。

**关键点**：基数与工资脱钩是最大的隐性再分配。工资 15,000 按 7,400 缴，单位少缴约 2,000 元/月，个人少缴约 800 元/月，当期到手多、长期养老金少。

### 4.2 个税（2025 年）

**综合所得年度税率**（工资薪金、劳务报酬、稿酬、特许权使用费合并）：

| 应纳税所得额（年） | 税率 | 速算扣除数 |
|---|---|---|
| ≤36,000 | 3% | 0 |
| 36,000–144,000 | 10% | 2,520 |
| 144,000–300,000 | 20% | 16,920 |
| 300,000–420,000 | 25% | 31,920 |
| 420,000–660,000 | 30% | 52,920 |
| 660,000–960,000 | 35% | 85,920 |
| >960,000 | 45% | 181,920 |

- 基本减除费用 5,000 元/月（6 万/年）；专项附加扣除：子女教育 2,000/月/孩、3 岁以下照护 2,000/月/孩、赡养老人 3,000/月、房贷利息 1,000/月、住房租金 1,500/1,100/800、继续教育 400/月、大病医疗据实（上限 8 万）。
- 工资薪金用**累计预扣法**，年初税率低、年末跳档。

**全年一次性奖金**：2027-12-31 前可选择单独计税（奖金÷12 查月度税率表，3%–45%），也可并入综合所得。**中低收入者单独计税更优，高收入者需试算**。

**劳务报酬预扣**：

| 每次收入 | 预扣应纳税所得额 | 预扣率 |
|---|---|---|
| ≤800 元 | 0 | 不预扣 |
| 800–4,000 元 | 收入−800 | 20% |
| 4,000–20,000 元 | 收入×80% | 20% |
| 20,000–50,000 元 | 收入×80% | 30%（速算 2,000） |
| >50,000 元 | 收入×80% | 40%（速算 7,000） |

年度汇算时，劳务报酬按**收入×80%** 并入综合所得，再减 6 万和各项扣除。所以"800 元以下免税"只在预扣环节成立，**不是年度免税额度**。

**经营所得**：5%–35% 五级超额累进（3 万/9 万/30 万/50 万档），可核定征收；小规模纳税人月销售额 10 万以下免增值税，超征 1%（2023–2027 优惠）。

**其他**：股息红利 20%；财产租赁 20%；偶然所得 20%；个人养老金领取 3%。

### 4.3 劳动基准

| 项目 | 标准 |
|---|---|
| 加班费 | 工作日 150%、休息日 200%（或调休）、法定节假日 300%【制度】 |
| 经济补偿 | N（每满 1 年 1 个月）；代通知金 +1；违法解除 2N；高收入者按社平 3 倍封顶 |
| 试用期 | 合同 3 个月–1 年→≤1 个月；1–3 年→≤2 个月；3 年以上→≤6 个月；工资 ≥ 转正 80% |

### 4.4 2025 年三个重要变化

1. **2025-09-01**：最高法《劳动争议司法解释（二）》第 19 条——用人单位与劳动者约定不缴社保的，约定无效；劳动者可解除合同并主张经济补偿。低基数/不缴社保的"自愿协议"失去效力。
2. **2025-01-01**：渐进式延迟退休启动，男职工 60→63、女干部 55→58、女工人 50→55，15 年过渡；最低缴费年限 2030 年起从 15 年逐步提高到 20 年。
3. **2025 年**：新就业形态职业伤害保障试点扩围；平台涉税信息按季报送（2025 年 10 月首次），灵活用工"不申报"空间收窄。

### 5.3 可视化时容易犯的错

- 把公积金当"税"——它是个人资产，应单独一条流回到个人账户。
- 把单位社保当"单位成本"却不画——它占单位成本 26%–38%，是最大的一块。
- 用"税前工资"做起点——不同形态的税前工资不可比，应该用**单位总成本**做起点。
- 忽略年终奖的税档跳跃——年终奖单独计税会让 3.6 万/14.4 万/30 万/42 万/66 万/96 万这几个临界点出现"多发一元、多缴几千"的断崖。

## 6. 常见误区与不确定性

1. **"月薪"不可比**：体制内 8k 含高公积金+职业年金，民企 12k 可能按最低基数缴，实际总包可能反过来。
2. **"社保基数=工资"是错觉**：低基数缴费在当期多拿现金，在退休后少拿养老金，是跨期再分配。
3. **"劳务报酬 800 元起征"是误读**：800 元只是预扣门槛，年度汇算按 80% 并入综合所得。
4. **"经营所得一定更省税"**：核定征收下可能省，但查账征收+无成本票时税负可能高于工资薪金。
5. **"平台抽成"不是税**：它不进财政，是私人部门的分成，桑基图要单独画。
6. **统计口径陷阱**：城镇非私营单位平均工资约为私营单位的 1.6–1.9 倍，用哪个口径会改变所有结论。
7. **2026 年变量**：社保费率、最低工资、个税优惠、平台监管均可能调整；本文数据截至 2025 年末。
